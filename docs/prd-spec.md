# PRD 编写规范

> 版本: v1.0 | 日期: 2026-06-25

---

## 1. 目的

统一 SmallShrimp 项目所有子模块的 PRD 文档结构与颗粒度，确保跨模块 PRD 可互相引用、可横向对比。

---

## 2. 文档组织

```
docs/
├── prd-spec.md              # 本规范（编写标准）
├── prd-index.md             # PRD 索引（列出所有 PRD 及关联）
├── templates/
│   └── PRD-TEMPLATE.md      # 标准 PRD 模板
├── desktop/                 # 桌面端
│   ├── PRD.md
│   └── DEVLOG.md
├── backend/                 # 后端服务（未来）
├── web/                     # Web 前端（未来）
└── mobile/                  # 移动端（未来）
```

---

## 3. 固定章节结构

所有 PRD 必须包含以下 9 章，顺序不可变：

| 章节 | 标题 | 必填 |
|------|------|------|
| 1 | 产品概述 | ✅ |
| 2 | 功能范围 | ✅ |
| 3 | 技术架构 | ✅ |
| 4 | UI/交互设计 | ✅ |
| 5 | 模块详细设计 | ✅ |
| 6 | API 设计 | ✅ |
| 7 | 里程碑 & 时间线 | ✅ |
| 8 | 风险 & 缓解 | ✅ |
| 9 | 附录 | ✅ |

可选子章节（如 5.1、5.2）按需展开。

---

## 4. 功能颗粒度标准

### 4.1 优先级定义（所有 PRD 共用）

| 优先级 | 含义 | 颗粒度要求 |
|--------|------|-----------|
| **P0** | 必须实现，缺了产品不可用 | 每个功能点一行表格行，含「功能名称 + 一句话说明」 |
| **P1** | 应该实现，显著提升体验 | 可展开为 2-3 列表格，含简要交互描述 |
| **P2** | 可以后做，锦上添花 | 只列功能名称，细节在独立设计文档中展开 |

### 4.2 P0 功能写法示例

```markdown
| 模块 | 功能 | 说明 |
|------|------|------|
| **进程管理** | 一键启动/停止服务 | 托盘图标常驻，显示运行状态 |
```

✅ 一行搞定，不多写。

❌ 不要在 P0 表格中展开交互流程、状态机、错误处理——这些属于第 5 章。

### 4.3 何时拆分独立设计文档

当某个 P2 功能的模块设计超过一页（~50 行），应拆为独立文档：

```
docs/desktop/
├── PRD.md                   # 主 PRD（只列 P2 功能名）
├── designs/
│   └── memory-panel.md      # 记忆面板详细设计
```

主 PRD 中通过 `@ref` 引用。

---

## 5. 版本号规则

```
v<主版本>.<修订版本>

主版本: 跟随产品大版本（如 v1.0 = SmallShrimp 1.0）
修订版本: 文档自身修订次数（v1.0 → v1.1 → v1.2）
```

所有子模块 PRD 共享同一主版本号。

---

## 6. 交叉引用格式

引用其他 PRD 或设计文档时，使用以下格式：

```markdown
@ref: backend/PRD.md#6.1       → 指向后端 PRD 第 6.1 节
@ref: desktop/PRD.md#5.5       → 指向桌面端 PRD 第 5.5 节
@ref: designs/memory-panel.md  → 指向独立设计文档
```

**原则：引用，不重复。** 涉及跨模块功能时，在自己 PRD 中只写本模块负责的部分，其余用引用。

---

## 7. 变更记录

每个 PRD 的 9.2 节必须维护变更记录表：

```markdown
| 日期 | 版本 | 变更 |
|------|------|------|
| 2026-06-25 | v0.1 | 初始草案 |
| 2026-06-26 | v0.2 | 新增 XX 模块 |
```

---

## 8. DEVLOG 规范

每个子模块目录下的 `DEVLOG.md` 记录开发进度，格式统一：

```markdown
# 开发日志

> 项目：<模块名>
> 最后更新：YYYY-MM-DD

## 当前状态
- 阶段：<当前阶段>
- 整体进度：X%

## 进度总览
| 阶段 | 状态 | 开始 | 完成 |
|------|------|------|------|

## 日志
### YYYY-MM-DD
- 条目
```
