> 版本: v0.1 | 日期: 2026-06-25 | 状态: 草案

## 1. 产品概述

### 1.1 产品定位

技能系统管理面板，让用户浏览、启用/禁用 SmallShrimp 的 Skill，以及浏览安装社区 Skill。

### 1.2 核心价值

| 痛点（现状） | 解决 |
|---|---|
| Skill 管理靠文件系统 | 面板式浏览，一键启用/禁用 |
| 发现 Skill 靠社区文档 | 插件市场浏览安装 |
