# MCP 工具管理 — 产品需求文档

> 版本: v0.1 | 日期: 2026-06-25 | 状态: 草案

---

## 1. 产品概述

### 1.1 产品定位

MCP 工具管理面板，让用户可视化查看、管理已连接的 MCP Server 及其提供的工具，测试连通性，按需启用/禁用工具。

### 1.2 核心价值

| 痛点（现状） | 解决 |
|---|---|
| MCP 连接状态黑盒，不知道哪些 Server 可用 | 实时显示连接状态（在线/离线/错误） |
| 不知道 MCP Server 提供了哪些工具 | 展开浏览工具列表及参数 Schema |
| 工具粒度控制只能改配置 | 面板内一键启用/禁用工具 |

---

## 2. 功能范围

### 2.1 V1（P1 — 体验完善）

| 模块 | 功能 |
|------|------|
| **MCP Server 列表** | 查看已配置的 MCP Server，展示连接状态（在线/离线/错误） |
| **工具浏览** | 展开 Server 查看提供的工具列表、参数 Schema |
| **连通性测试** | 手动触发连接测试，显示错误详情 |

### 2.2 V2（P2）

| 模块 | 功能 |
|------|------|
| **工具启用/禁用** | 按工具粒度启用/禁用（写入配置，热生效） |
| **工具调用日志** | 查看 MCP 工具的调用历史 |

## 4. 后端 API 层

| 端点 | 方法 | 用途 | 优先级 |
|------|------|------|--------|
| `/api/mcp/servers` | GET | MCP Server 列表 + 连接状态 | P1 |
| `/api/mcp/servers/:name/tools` | GET | 获取该 Server 的工具列表 | P1 |
| `/api/mcp/servers/:name/test` | POST | 连通性测试 | P1 |
| `/api/mcp/tools/:name/toggle` | PUT | 启用/禁用工具 | P2 |

## 5. 桌面端 UI 层

**列表视图：**

```
┌─────────────────────────────────────────┐
│  🔌 MCP 工具管理                         │
│  ─────────────────────────────────────── │
│  ┌─────────────────────────────────────┐ │
│  │ 🟢 filesystem         [测试连接] ▼  │ │
│  │   ├─ 📁 read_file                  │ │
│  │   ├─ ✏️ write_file            ✅   │ │
│  │   └─ 📋 list_directory        ✅   │ │
│  ├─────────────────────────────────────┤ │
│  │ 🔴 remote_db           [测试连接] ▼  │ │
│  │   (连接失败: timeout)               │ │
│  └─────────────────────────────────────┘ │
└─────────────────────────────────────────┘
```

- 每个 Server 可展开/折叠工具列表
- 状态指示：🟢 在线、🟡 连接中、🔴 离线/错误
- 点击「测试连接」触发连通性检测
- P2: 工具右侧开关控制启用/禁用
