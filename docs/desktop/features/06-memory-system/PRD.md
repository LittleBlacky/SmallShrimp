# 记忆系统 — 产品需求文档

> 版本: v0.1 | 日期: 2026-06-25 | 状态: 草案

---

## 1. 产品概述

### 1.1 产品定位

记忆系统管理面板，让用户可视化查看、搜索、编辑 SmallShrimp 的 5 层记忆体系。

### 1.2 核心价值

| 痛点（现状） | 解决 |
|---|---|
| 记忆存储在文件系统，难以浏览 | 面板式查看，按层分类 |
| 无法搜索记忆 | 全文搜索，支持关键词过滤 |

---

## 2. 功能范围

### 2.1 V2（P2）

| 模块 | 功能 |
|------|------|
| **记忆查看** | 按层（profile/facts/projects/reflections/sessions）分类展示 |
| **记忆搜索** | 全文搜索，支持关键词过滤 |
| **记忆编辑** | 编辑/删除单条记忆 |

---

## 3. 后端 API 层

| 端点 | 方法 | 用途 | 优先级 |
|------|------|------|--------|
| `/api/memories` | GET | 记忆列表/搜索 | P2 |
| `/api/memories/:id` | PUT/DELETE | 编辑/删除记忆 | P2 |
